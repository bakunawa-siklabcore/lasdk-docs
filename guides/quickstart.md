# Getting started

LASDK is preparing for a closed beta and is not yet available for general use. Setup instructions are provided to invited participants for the specific beta build and supported coding tools.

Before using a beta build, confirm that your AI coding tool is on the supported list and review its access, data, and privacy settings. The coding tool or AI provider may receive project context according to the provider and settings you choose.

For access enquiries, see the [product overview](../index.md) or contact Siklab Core at [lasdk@siklabcore.com](mailto:lasdk@siklabcore.com).
