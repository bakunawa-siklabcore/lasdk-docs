# Help and troubleshooting

LASDK is in active development, so setup and support instructions may change. Confirm that you are using a supported release and follow the instructions shipped with it.

If you need help, contact Siklab Core at [lasdk@siklabcore.com](mailto:lasdk@siklabcore.com) and include the product version and a short description of the issue. Do not include passwords, private keys, access tokens, customer data, or confidential project files.
