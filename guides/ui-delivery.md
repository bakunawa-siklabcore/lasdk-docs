# Reviewing interface work

Interface work can look polished in one view and still have problems at another size or for another user. LASDK is intended to help teams include interface work in AI-assisted delivery and review the result with relevant context.

The specific interface checks available depend on the supported beta build and its setup. LASDK does not guarantee that an interface is accessible, usable, correct, or ready to ship. People remain responsible for checking the result against their needs.
