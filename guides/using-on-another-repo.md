# Using LASDK with a project

LASDK is being developed for AI-assisted software work on projects you control, including use as a product in its own right as well as within Siklab Core. For closed beta, confirm the supported repository types and setup with Siklab before connecting a project.

Before connecting a project, review the coding assistant's access and data settings and follow your team's policies. The assistant or its provider may receive project context according to the settings you choose.
